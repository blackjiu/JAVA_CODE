# 抽象类 `abstract`

---

## 一、抽象方法

### 什么是抽象方法？
当父类无法提供通用实现的方法时，就用**抽象方法**。
- 特点：**只有声明，没有实现**（没有方法体）。
- 作用：**强制子类重写**，不然代码会报错。

> 例子：
> 父类 `Person` 是“人”，但“人”本身是抽象的，没有确定的工作内容，所以 `work()` 不应该有具体实现，就定义为抽象方法，让子类 `Student`、`Teacher` 去重写。

### 核心规则
- 如果一个类中存在抽象方法，那么**该类必须声明为抽象类**。
- 抽象方法：只有声明，没有实现，强制子类必须重写。

### 格式
1.  **抽象方法的定义格式**
    ```java
    public abstract 返回类型 方法名(参数列表);
    ```
    示例：
    ```java
    public abstract void work();
    ```

2.  **抽象类的定义格式**
    ```java
    public abstract class 类名 {
        // 可以包含普通方法、成员变量、抽象方法
    }
    ```
